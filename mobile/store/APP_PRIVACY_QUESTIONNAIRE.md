# App Store Connect — App Privacy (nutrition labels)

## Data linked to the user

Generally **No** — the app developer does not operate a login backend. Users enter server credentials stored locally.

## Data used to track you

**No**

## Data collected (declare per category in App Store Connect)

### Contact Info
- None collected by developer

### User Content
- **Photos or Videos** — App Functionality — Not linked — Only when user broadcasts (sent to configured server)
- **Audio** — App Functionality — Not linked — Only when user broadcasts
- **Other User Content** (chat) — App Functionality — Not linked — Sent to configured server

### Identifiers
- **User ID** — if chat nickname counts: App Functionality — Not linked — Stored locally / sent as chat nick

### Usage Data
- None collected by developer (optional: if you add analytics later, update this)

## Privacy Policy URL

https://indep.stream/privacy

## Moderation (Guideline 1.2)

Chat moderation is enforced **on the livecam server** (ban, timeout, slow mode). Users connect to servers they trust. In-app reporting is not in v1; document server operator contact for abuse.
